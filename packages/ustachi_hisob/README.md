# ustachi_hisob

Rom va eshik chizmasi — mijoz va usta ilovasi uchun umumiy Dart paketi (Flutter'siz).

- `design.dart` — chizma daraxti: `FrameDesign`, `Zone` (oyna o'rni), `Split` (impost), `Wing` (qanot);
- `design_codec.dart` — chizmani JSON'ga yozish va o'qish;
- `layout.dart` — kataklarning mm'dagi joylashuvi (rama, impost va qanot enlari bilan);
- `edit.dart` — tahrirlash amallari: bo'lish, birlashtirish, qanot, o'lcham, kamar;
- `validate.dart` — chizma to'g'riligini tekshirish;
- `series.dart` — profil enlari (chizma uchun).

Tekshirish: `dart test`.
