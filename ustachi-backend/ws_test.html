2. Token olish (ixtiyoriy — tokeningiz bo'lsa kerak emas)

Bu qism file:// dan ishlamaydi — serverda CORS faqat localhost va Netlify uchun ochiq. Shu papkada terminal ochib python -m http.server 8080 ni ishga tushiring va sahifani http://localhost:8080/ws_test.html dan oching. WebSocket testining o'ziga bu shart emas — u CORS'ga bo'ysunmaydi.

3. Uzilishni tekshirish

Avto-ping o'chiq holda qoldiring va kuting. Ulanish 30–120 soniyada 1006 bilan uzilsa — sabab tarmoq/NAT yoki proksi timeout'i, server tomonda heartbeat yo'qligi. Keyin avto-ping'ni yoqib qayta sinang: uzilmasa, tashxis tasdiqlanadi.
